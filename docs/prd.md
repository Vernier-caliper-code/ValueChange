## 3. 用户与使用场景

### 3.1 目标用户

| 优先级 | 人群 | 诉求 |
|--------|------|------|
| P0 | 想入门 AI 开发的新手 / 转行者 | 系统的、能跟着做的实战内容 |

- 作为一个其他行业从业者，我希望看到 AI 结合本行业的案例与思路，以便找到 AI+X 的切入点
- 作为一个潜在合作方，我希望快速了解作者的能力与在售商品，以便判断是否值得联系

## 5. 功能需求详述

### 5.1 站点结构

- 顶部导航：`首页 / AI全栈 / AI工具 / 经验分享 / 商品 / 关于我`
- 右上角：未登录显示"登录/注册"；已登录显示用户名，点击出现"退出登录"
- 后台入口不在导航展示，路径不公开

### 5.2 首页

- **功能描述**：网站门面，承担简介、导流、精选曝光
- **内容**：网站简介（一句话讲清 ValuePass 是什么）+ 四大板块入口卡片 + 精选内容区
- **业务规则**：精选内容由后台手动勾选（文章/工具/商品可混排），勾选自后台"精选管理"；取消勾选立即从首页消失
- **异常**：无任何精选时，精选区展示"最新发布"兜底文案+最近内容，不出现空白

### 5.3 文章系统

- **前置条件**：发布操作需管理员登录后台；游客阅读无限制
- **编辑器**：Markdown + 实时预览（技术文章代码块刚需）
- **字段**：
  - 标题（必填）
  - 正文（Markdown，必填）
  - 封面图（选填，未上传用默认占位图）
  - 摘要（选填，未填自动截取正文前 150 字，用于列表卡片与 SEO description）
  - 所属板块（必选：AI全栈 / 经验分享）
  - 状态：草稿 / 已发布
  - 发布时间（发布时自动记录，可手动修改，便于搬运旧文）
- **不做**：标签、评论、阅读量显示
- **操作流程**：后台新建/编辑 → 保存草稿或发布 → 前台对应板块列表与文章页可见

### 5.4 AI 工具板块

- **功能描述**：分享好用的开发软件、MCP、Skill 等
- **后台字段**：工具图片、名称、功能摘要、介绍、官网链接
- **前台**：图片卡片列表 → 点击图片进站内详情页 → 详情页含名称/功能摘要/介绍 + "前往官网"按钮（新窗口打开）
- **不做**：分类、星级/推荐指数、免费/付费标签

### 5.5 商品展示

- **功能描述**：个人商品展示（不在线售卖）
- **字段**：商品图（可多张）、名称、文字描述；不显示价格；状态：在售 / 已下架
- **转化路径**：详情页展示微信二维码作为咨询入口，站外联系成交
- **异常分支**：访问已下架商品旧链接 → 显示"该商品已下架" + 引导浏览其他商品

### 5.6 关于我 / 联系页

- 个人简介 + 微信号（含二维码图片）
- 不做留言表单

### 5.7 用户注册登录

- **定位**：本期只铺路、无权益；**未登录游客可浏览全站全部内容，不受任何拦截**
- **注册**：账号 + 密码 + 确认密码（账号唯一；密码 ≥ 8 位为原则性默认值，实现时可调整）；注册成功自动登录
- **登录**：账号 + 密码；登录成功跳回原浏览页面；右上角显示用户名 + 退出入口
- **找回密码**：本期不做自助找回；用户忘记密码联系站长，站长在后台手动重置
- **安全规则**：密码哈希存储（不可逆）；同一 IP/账号连续失败 5 次锁定 15 分钟；登录失败统一提示"账号或密码错误"（不透露具体哪个错）
- **注册失败**：用户名已存在 → 明确提示"该用户名已被使用"

### 5.8 后台管理

- **前置条件**：仅一个管理员账号（部署时设置，不走注册页）；未登录访问后台一律跳登录页
- **功能模块**：
  1. 管理员登录
  2. 文章管理：列表（按板块/状态筛选）、新建、编辑、删除、发布/撤回
  3. 工具管理：增删改查
  4. 商品管理：增删改查、上架/下架
  5. 精选管理：勾选文章/工具/商品上首页精选位
  6. 用户管理：查看用户列表（用户名、注册时间）、**禁用账号**、**手动重置密码**
  7. 图片上传：编辑文章/工具/商品时直接上传（单张 ≤ 5MB），不做独立媒体库

### 5.9 异常分支汇总

| # | 场景 | 处理 |
|---|------|------|
| 1 | 板块无内容（空状态） | 显示"内容筹备中"占位文案 + 默认图，不出现空白页 |
| 2 | 访问不存在的 URL | 404 页 + 回首页按钮 |
| 3 | 已下架商品链接 | "该商品已下架" + 推荐浏览其他商品 |
| 4 | 用户名已存在 | 明确提示 |
| 5 | 登录失败 | 统一提示"账号或密码错误"；5 次失败锁 15 分钟 |
| 6 | 图片上传超限/失败 | 提示原因、可重试，不丢已填写表单 |
| 7 | 未登录访问后台 | 强制跳登录页 |
| 8 | 并发 | 本期只有单管理员、无库存、无多人编辑——**本期无并发场景** |
| 9 | 统计脚本加载失败 | 不影响网站正常功能 |

## 6. 非功能需求

- **性能**：首屏加载 < 2 秒；后台操作响应 < 1 秒；图片统一 WebP 压缩 + 懒加载
- **兼容性**：PC + 手机响应式适配（双端 P0）；支持 Chrome / Edge / Safari / Firefox 最新版；不兼容 IE
- **部署**：Vercel；数据库用托管 Postgres 免费层（Vercel Postgres / Neon / Supabase 开发时三选一）；域名先用 Vercel 免费子域名
- **安全**：全站 HTTPS；密码哈希存储；登录失败限流（5 次/15 分钟）；基础防 SQL 注入/XSS；后台入口路径不公开；密钥不入代码与仓库
- **合规**：最小化收集用户信息（仅账号+密码哈希，不收集邮箱）；底部挂简版隐私说明

## 7. 数据需求

### 7.1 埋点

- 全站页面 PV/UV（按首页/文章页/工具页/商品页/关于页细分）——百度统计自动采集

  - 工具详情页"前往官网"外链点击

### 7.2 报表

- 不在自家后台做报表页，统一在百度统计官网后台查看；文章阅读量不统计展示（后期可补）

## 8. 验收标准（Acceptance Criteria）

| # | 验收条件（Given-When-Then） |
|---|------------------------------|
| 1 | Given 管理员已登录后台，When 新建文章填标题+正文+选板块并发布，Then 前台对应板块立即可见且文章页可访问 |
| 2 | Given 已有发布内容，When 后台勾选/取消精选，Then 首页精选位立即出现/消失 |
| 3 | Given 已发布工具，When 游客点击工具图片，Then 进站内详情页；点击"前往官网"在新窗口打开官网 |
| 4 | Given 在售商品，When 游客进入详情页，Then 可见图片+名称+文字描述+微信二维码 |
| 5 | Given 商品已下架，When 访问其旧链接，Then 显示"已下架"提示并引导浏览其他商品 |
| 6 | Given 游客在注册页，When 提交合法账号+密码+确认密码，Then 创建成功并自动登录；用户名重复时明确提示 |
| 7 | Given 已注册账号，When 正确账号密码登录，Then 登录成功且右上角显示用户名；连续 5 次失败则锁定 15 分钟 |
| 8 | Given 未登录状态，When 直接访问后台地址，Then 强制跳登录页；游客浏览全站内容不受任何拦截 |
| 9 | Given 不存在的 URL 或无内容板块，When 访问，Then 分别显示 404 页 / 空状态占位，不出现空白页 |
| 10 | Given 手机或 PC 访问，Then 布局正常可读，任意页面首屏加载 < 2 秒 |

## 9. 风险与依赖

### 9.1 风险

| # | 风险 | 缓解 |
|---|------|------|
| 1 | 免费 `vercel.app` 子域名在国内不稳定、百度收录弱（与搜索流量目标冲突） | 后期随时绑定自有域名或备案迁移 |
| 2 | 内容断更烂尾（个人站最大风险） | 上线前备好首批内容库，设定更新节奏 |
| 3 | 用户数据安全责任 | 密码哈希、HTTPS、最小化收集（不收集邮箱） |
| 4 | Vercel 免费额度超限 | 个人站量级基本够用，超量再升级 |
| 5 | 百度统计被广告拦截插件拦截 | 数据略低于实际，可接受 |
| 6 | 后台被暴力破解 | 登录限流 + 隐藏后台路径 |

### 9.2 依赖

1. Vercel 平台 + 托管 Postgres 免费层
2. 百度统计账号开通
3. Logo / favicon（已就绪 ✓）
4. 微信二维码图片素材（待提供）
5. 首批内容产出（16 条，硬性依赖，关联上线标准）
